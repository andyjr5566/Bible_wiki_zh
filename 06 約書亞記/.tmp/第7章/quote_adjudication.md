# 第7章 短引句裁決（--min-chars 2）

M3、M6 與 link_updates 都在送審前先跑過 `--min-chars 2`，三輪合計報出 18 處，逐條裁決如下。修正後兩個門檻（10 與 2）皆為 0 處未命中。

## M3 階段報出的 13 處

### 真的截斷或拼接（已補全）

- [經文] `我實在得罪了耶和華以色列的神。我所做的事如此如此：我在所奪的財物中……` → 我把書7:20 與書7:21 接成一句，而且把和合本的「耶和華─以色列的神」的破折號吃掉了。已拆成兩句分別引用，並補回破折號。
- [經文] `我兒，我勸你將榮耀歸給耶和華以色列的神，在他面前認罪，將你所做的事告訴我，不要向我隱瞞。` → 同上，缺破折號。已改為「耶和華─以色列的神」。
- [經文] `我兒，我勸你將榮耀歸給耶和華以色列的神，在他面前認罪` → 同一處的短版本，一併修正。

### 我自己的話被套上「」（已去引號）

- `一個人做的`、`家人為何同受刑罰`（一人犯罪全營受累）
- `他們到底有沒有被殺`、`一人犯罪、全民受累`、`兒女為何同死`（亞干的兒女為何同受刑罰）
- `石頭的堆`（堆石頭作記號）
- `為什麼會輸`（攻艾城失敗的原因）
- `違背約`（犯了罪（ma.al）；第15節的判詞原文是「因他違背了耶和華的約」，我壓縮成三個字又加引號）

以上都是我為了行文方便加的強調記號，不是來源的原話，已全部改成不帶引號的敘述。

### 英文來源的中譯被當成逐字引句（已改寫）

- `條、塊`、`金舌頭`（一條金子（le.shon za.hav））→ 前者是我對 la.shon 的中文轉寫，後者是 KC 的 “a golden tongue” 的中譯。已改為直接寫出 KC 的英文原文，中文說明不加引號；小標題也從「KC 從「金舌頭」讀出的一層意思」改成不帶引號的寫法。

## 另外在 B 類條目回查時修掉的五處既有錯誤（--entry 模式）

這五處不是本章寫的，是本章更新到的條目在前幾章留下的引句誤差；既然改到這些檔案就一併點狀修正：

- `link_folder/主題/認罪.md`：利5:5 引句 `他有了罪的時候，就要承認所犯的罪。` 末尾多了句號（和合本此處是逗號接下一句），已把句號移到引號外。
- `link_folder/主題/認罪.md`：丁良才那句原文作「與獻祭行按手體時的認罪未必是一事」（來源作「按手體」），舊版寫成「按手禮」並加引號＝非逐字。已改為不帶引號的轉述。
- `link_folder/主題/認罪.md`：`認罪就是將榮耀歸與神，使祂顯為公義。` 漏掉來源原有的括號，原文是「認罪就是將榮耀歸與神（書七19），使祂顯為公義。」已補回——這個括號正好就是本章的書7:19。
- `link_folder/背景/古代哀悼習俗.md`：創37:35 引句 `我必悲哀著下陰間到我兒子那裡` 漏了和合本的逗號，已補成「我必悲哀著下陰間，到我兒子那裡」（兩處）。
- `link_folder/地點/艾.md`：舊版把 KC 創13 的英文（“we must always return to the place where we last were with the Lord”）中譯後套「」，以及把 BH 的意思濃縮成「回到最初與神相遇之處」加引號。已改為英文原句進引號、中文說明不加引號。

## scan_unsourced_tokens 的 latin_needing_review 裁決（1 型、3 處）
