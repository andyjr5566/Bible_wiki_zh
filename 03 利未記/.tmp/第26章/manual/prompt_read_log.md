# Prompt 讀取回執：利未記 第26章

## manual/chapter_content.prompt.md
- 引句：依本章段落結構分成至少 3 個小節，每小節以「### 標題（vX-Y）」開頭；最後可加一個跨章脈絡／預表整理的主題小節。
- 引句：引述註釋請「直接引原話」並標明是哪一家（CT／GT／KC／BH 或 GT 內的《丁道爾》《舊約背景註釋》《中文聖經註釋》《精讀本》等），不要改寫成「CT指出…」的轉述體，也不可把甲家的話掛到乙家名下——已知實例：《舊約背景註釋》的古代近東材料被誤植為 KC、CT 的靈意註解被誤植為 KC。某一家在某處沒有說法，就不要替他生一個。
- 引句：不要寫「參考資料」清單——程式會自動附上來源 URL。

## manual/entry_batch_1.prompt.md
- 引句：STEP Bible 是原文證據層，不是第五套 commentary：可直接支持本章詞形、lemma、Strong 編號、morphology、context gloss 與 lexicon 義域等語言事實；不得把它算成CT／GT／KC／BH 的註釋共識票。
- 引句：development（選填）只收「跨書卷／跨章的主題遞進或預表發展」；同一段經文內的字義、詞源、各家詮釋辯論寫進 definition，不要塞進 development
- 引句：name：原文類用「中文（希伯來音譯）」，其餘用簡明中文；切勿把分類當音譯寫成「X（原文）」。音譯拼寫必須是上述來源文字中實際出現過的；來源沒給音譯就用裸中文名，不可憑聖經知識自行補配。
