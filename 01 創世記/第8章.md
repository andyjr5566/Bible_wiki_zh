2. 淵源和天上的窗戶都[[審判已過|閉塞了]]，天上的大雨也[[審判已過|止住了]]。
3. 水從地上漸退。過了[[四十天降雨與一百五十天水勢|一百五十天]]，水就漸消。
4. 七月十七日，方舟停在[[亞拉臘山]]上。
5. 水又漸消，到十月初一日，[[審判已過|山頂都現出來了]]。
6. [[信心與忍耐|過了四十天]]，[[挪亞]]開了方舟的窗戶，
7. 放出一隻[[烏鴉與鴿子的象徵|烏鴉]]去；那烏鴉飛來飛去，直到地上的水都乾了。
8. 他又放出一隻[[烏鴉與鴿子的象徵|鴿子]]去，要看看水從地上退了沒有。
9. 但遍地上都是水，鴿子找不著落腳之地，就回到方舟[[挪亞]]那裡，挪亞伸手把鴿子接進方舟來。
10. 他又等了七天，再把鴿子從方舟放出去。
11. 到了晚上，鴿子回到他那裡，嘴裡叼著一個新擰下來的[[橄欖葉子]]，[[挪亞]]就知道地上的水退了。
12. 他又等了七天，放出鴿子去，鴿子就不再回來了。
13. 到[[挪亞]]六百零一歲，正月初一日，地上的水都[[乾的兩個希伯來字|乾了]]。挪亞撤去方舟的蓋觀看，便見地面上乾了。
14. 到了二月二十七日，地就都[[乾的兩個希伯來字|乾了]]。
15. [[神的記念|神]]對[[挪亞]]說：
16. 你和你的妻子、兒子、兒婦都可以出方舟。
17. 在你那裡凡有血肉的活物，就是飛鳥、牲畜，和一切爬在地上的昆蟲，都要帶出來，叫他在地上[[新造與新生活|多多滋生，大大興旺]]。
18. 於是[[挪亞]]和他的妻子、兒子、兒婦都出來了。
19. 一切走獸、昆蟲、飛鳥，和地上所有的動物，各從其類，也都出了方舟。
20. [[挪亞]]為耶和華[[祭壇敬拜|築了一座壇]]，拿各類潔淨的牲畜、飛鳥獻在壇上為[[燔祭]]。
21. 耶和華聞那[[馨香之氣]]，就心裡說：我不再因人的緣故[[神的恩典之約|咒詛地]]（[[人的全面敗壞|人從小時心裡懷著惡念]]），也不再按著我才行的[[挪亞之約|滅各種的活物了]]。
22. [[洪水後自然秩序的保存|地還存留的時候，稼穡、寒暑、冬夏、晝夜就永不停息了]]。

## 本章整理

### 神記念，水勢漸退（1-5節）

創8:1以 וַיִּזְכֹּר（H2142，Qal）說「神記念」，受詞包括挪亞、方舟裡的一切活物和牲畜。敘事隨即記神使風經過地面，水便消退，因此「[[神的記念|神記念挪亞]]」在本段不只是一個內在念頭，也帶出實際的拯救行動。GT《串珠聖經註釋》據此把「記念」解為關注、顧念並施恩；《創世記雷氏研讀本》說是想到要給予愛心的關懷；《聖經精讀本》則說這是時常掛在心上的狀態。GT賈斯樂郝威也從神的全知解答[[神是否暫時忘記了挪亞|常見疑問]]：這裡描述的是神按承諾介入的時刻。洪水的水源閉塞、大雨止住、水勢逐步下降，顯明[[審判已過|審判轉向恢復]]。

STEP把退水寫得很具體：1節 וַיִּשֹׁכּוּ（H7918）是「水消退」；2節的泉源和天窗「被關閉」、雨「被止住」；3節以兩個不定詞 הָלוֹךְ וָשׁוֹב 描寫水持續退回，又用 וַיַּחְסְרוּ（H2637）說水量減少；5節再以「持續減少」推進到山頂顯露。KC進一步把這段漸進過程用於牧養：試煉可以停止，留下的後果卻可能需要時間消退。

「神叫風吹地」使用 רוּחַ（*ruach*，H7307H）；STEP在本句給的語境義是「風」，簡要義域則包括氣息與靈。CT、GT與BibleHub進一步把這個[[風與靈同字|同字現象]]與創1:2神的靈運行在水面上相照，視洪水後的秩序恢復為再創造；CT又把神的記念、方舟與風分別連於父、子、靈的救恩工作，以[[三一神同工]]整理這段豫表。

第4節先用 וַתָּנַח（H5117，Qal）說方舟「停住／安歇」，地點則是 הָרֵי אֲרָרָט：「[[亞拉臘山|亞拉臘眾山]]」。הָרֵי 是「山」的複數構造式，亞拉臘則是地名。GT各家因此把它理解為烏拉爾圖／古亞美尼亞一帶的山區，而非只鎖定今日某一座山峰。《丁道爾聖經註釋》提到凡湖附近的烏拉圖，《雷氏研讀本》也以連綿山脈解釋；《舊約背景註釋》則比較《吉加墨斯史詩》明指尼西爾山的寫法。至於[[亞拉臘山與方舟遺跡爭議|方舟遺跡]]，GT收錄過俄國探險隊與冰中船體等傳聞；BibleHub指出目前仍缺少能確定精確遺址的證據。

### 洪水消退時間軸（1-14節）

| 時點 | 事件 | 資料性質 |
|---|---|---|
| 挪亞600歲，2月17日 | 洪水爆發（7:11） | 經文明載 |
| 7月17日 | 方舟停在亞拉臘山區（8:4） | 經文明載 |
| 10月1日 | 山頂顯露（8:5） | 經文明載 |
| 再過40天 | 挪亞開窗，放出烏鴉（8:6-7） | 經文明載間隔 |
| 其後三次放鴿 | 第二、三次前各等7天（8:8-12） | 首次與烏鴉相隔7天是來源推算 |
| 挪亞601歲，1月1日 | 地面沒有積水，挪亞撤去方舟蓋（8:13） | 經文明載 |
| 2月27日 | 地全然乾透，神命挪亞出方舟（8:14-16） | 經文明載 |

GT第7章拾穗時間表以三十日月份推算若干日期，並給出371日總數；GT第8章所收另一研讀本則說挪亞一家在方舟共377天，包含洪水前七天的等候。兩者的差別來自「只算洪水起訖」或「連進舟後七天也算」以及首尾日算法，不能把任一總數當成單節經文明言。可確定的是：洪水從六百歲二月十七日開始，到六百零一歲二月二十七日地全乾，來源稱為一年又十天；挪亞在洪水前已進舟等候七天。

第13、14節的「乾了」使用[[乾的兩個希伯來字|兩個不同希伯來字]]：13節兩次用 חָרְבוּ（H2717A，Qal完成式）說水乾退、地面已乾；14節用 יָבְשָׁה（H3001，Qal完成式）說地已乾燥。GT據上下文說明，13節著重地面不再有積水，14節則描述土地乾透。挪亞在正月初一已親眼看見地面乾了，仍等到二月二十七日神說話才出方舟；CT與GT由這五十多天進一步討論[[信心與忍耐]]。

### 烏鴉、鴿子與橄欖葉（6-12節）

| 鳥與次序 | 敘事中的作用 | 來源的靈意閱讀 |
|---|---|---|
| 烏鴉 | 飛來飛去直到地面乾；食腐、能在較差環境停留 | CT、GT、KC以不潔淨的烏鴉象徵舊造或肉體 |
| 第一次鴿子 | 找不到落腳地，返回方舟 | 以基督為安息，不以受審判之物為落腳處 |
| 第二次鴿子 | 叼回新擰的橄欖葉，顯示植物恢復 | 橄欖與油連於聖靈，嫩葉象徵新生命 |
| 第三次鴿子 | 不再返回，顯示外界已可棲息 | CT解作聖靈在潔淨生命中安家 |

STEP把兩種鳥和牠們的行動分得很清楚：7節的 עֹרֵב（H6158）是烏鴉，並以 יָצוֹא וָשׁוֹב 描寫牠持續飛出又返回；8節的 יוֹנָה（H3123）是鴿子，9節說牠找不到 מָנוֹחַ（H4494，「落腳／安歇之處」），挪亞便伸手把牠帶回方舟。11節使用 עֲלֵה（H5929，「葉」）和 זַיִת（H2132H，「橄欖」），並以 טָרָף（H2965）特別說明那是「新擰／新摘下的」。這些行動使挪亞能觀察水與土地的狀態；CT、GT與KC再按利11:15、太3:16等經文，將[[烏鴉與鴿子的象徵|烏鴉和鴿子]]進一步應用為舊造性情與聖靈、新生命。丁道爾則先把[[橄欖葉子|橄欖葉]]理解為「新造的應許」，後世又由此發展出口銜橄欖枝的和平圖像。

GT背景資料將本章與[[古代近東洪水故事中的放鳥情節|古代近東洪水故事]]比較：

| 來源 | 放鳥次序 |
|---|---|
| 創世記8章 | 烏鴉一次，鴿子三次 |
| 吉加墨斯史詩 | 鴿子、燕子、烏鴉 |
| 阿特拉哈西斯傳統 | 也有以鳥探察外界的情節 |

這一點 GT《舊約背景註釋》講得最完整：「古代的領航員有用鳥來尋找陸地的習慣，但挪亞已經登陸，無需導航。他使用雀鳥不是要斷定方向。此外，雀鳥的飛行路線有時也作觀兆之用。但創世記和吉加墨斯都沒有觀察放出雀鳥的航線。」背景註釋另分別說明兩種鳥的習性：烏鴉「對航海者的功用是牠的航線……食腐肉是烏鴉的習性，因此必然有足夠的食物」；斑鳩和鴿子「續航能力有限，領航員利用牠們來斷定登陸地點。牠們自行回來，就證明附近沒有可供著陸之處」。這與敘事完全吻合——《創世記雷氏研讀本》即說烏鴉「棲息在泥濘的地面也毫無不安，所以顯然不會返回方舟」，而鴿子「不會在不潔淨的地方著陸，所以牠返回方舟去」。GT 丁良才由此發出勸勉：「鴿子的本性只好落在又乾燥又潔淨的地方……為聖徒的切不要學烏鴉，以不潔之物充饑而知足，應該像鴿子等候新天新地。」GT《聖經精讀本》則從另一面看：「溫柔脆弱的鴿子能夠做到強壯的烏鴉沒能完成的事情，象徵著神揀選那些軟弱之人傳播福音的事工（林前1:27-29）。」

### 出方舟與新造生活（15-19節）

挪亞因神的命令進方舟（7:1），也等神命令才出方舟。8:16的 צֵא（H3318G）是第二人稱單數命令式「出去」；17節再用使動命令式 הַיְצֵא（H3318H）吩咐他把各類活物帶出來，並接著使用「滋生」שָׁרַץ（H8317）、「結果／繁衍」פָּרָה（H6509）和「增多」רָבָה（H7235A）。19節還說活物按各自的「家族」מִשְׁפָּחָה（H4940）出方舟。註釋把這組繁衍用語與創1章的創造使命相照，看作[[新造與新生活]]的開端。

| 創世記1章 | 創世記8章 |
|---|---|
| 神的靈運行在水面上（1:2） | 神叫風 *ruach* 吹地（8:1） |
| 水聚在一處、旱地顯露（1:9） | 水退、山頂與地面顯露（8:5、13） |
| 活物各從其類（1:20-25） | 動物各從其類出方舟（8:19） |
| 活物滋生眾多（1:22） | 活物多多滋生、大大興旺（8:17） |

CT與KC把出方舟到更新之地解作與基督同死同復活、行在生命新樣中（羅6:4）；彼前3:20-21則明文以挪亞一家藉水得救連於[[洪水與洗禮的豫表|洗禮與基督復活]]。

### 築壇、燔祭與馨香（20-21節）

第20節以 מִזְבֵּחַ（H4196）稱挪亞為耶和華所築的「壇」；又用 וַיַּעַל（H5927I，Hiphil）說他把祭物「獻上」，所獻的是複數 עֹלֹת（H5930A，「燔祭」）。祭物取自潔淨牲畜和潔淨飛鳥，也讓第7章多保存潔淨活物的安排在這裡顯出獻祭用途。GT《聖經精讀本》指出這是聖經第一次明用「壇」一詞，並由其字源和古代祭壇位置補充背景；《舊約背景註釋》則說明舊約祭壇並不把祭物當成供養神明的食物。挪亞蒙拯救後先築壇，遂成為[[祭壇敬拜|敬拜與獻上]]的重要圖像。

STEP可直接確認的祭名是[[燔祭]]；到後來的祭儀制度中，עֹלָה與「上升」相連，整個祭物焚燒獻上。GT《舊約背景註釋》從祭名和古代背景出發，提醒燔祭在不同處境中用途廣泛。CT、GT與KC則進一步把挪亞的祭理解為感恩、敬拜與全然奉獻，並以燔祭豫表基督在十字架上的完全獻上；KC又把牲畜與飛鳥分別應用為基督在地為人及從天而來。

「耶和華聞那[[馨香之氣]]」在原文由 רֵיחַ（H7381，「氣味／香氣」）與 הַנִּיחֹחַ（H5207，「舒暢、悅納的」）組成。GT《雷氏研讀本》譯作「滿意的味道」，丁良才與《串珠》把它解為擬人化語言，表示神悅納祭物和挪亞的敬拜。《舊約背景註釋》又把這語彙放進古代脈絡：美索不達米亞故事也寫神明被祭物香氣吸引，甚至依賴供物；舊約使用生動的「馨香」語彙，焦點卻在祭物蒙神悅納。CT與KC再按弗5:2把這份悅納連於基督的獻上。

### 人心仍惡，神仍施憐憫（21-22節）

第21節以 יֵצֶר（H3336，「傾向／意念」）、לֵב（H3820A，「心」）、רַע（H7451H，「惡」）和 מִנְּעֻרָיו（H5271A，「從幼年」）說明人的內在傾向。第6章以相近語彙說明洪水審判的原因；第8章在同一人性現實中，卻接著兩次使用「我不再／不再重複」אֹסִף（H3254G），宣告不再照這次洪水「擊打」נָכָה（H5221）各種活物。KC進一步指出，洪水沒有改變人的內心；上下文的轉折在於祭物蒙悅納，以及神主動選擇以憐憫保存世界。[[神是否改變心意|神旨意的討論]]也應放在這個救贖歷史轉折中理解。

> [!quote] KC
> 第一次的話說在洪水之前，第二次說在洪水之後。審判並沒有改變人的心；如今神乃是基於燔祭的馨香看待這地。惡是人與生俱來的，這使人更全然倚靠神的恩典。

第8章先有神在心裡的應許，第9章才正式向挪亞一家及一切活物宣告約並賜下虹的記號。GT把這世界保存應許列為「[[無條件之約]]」，意思是經文沒有把季節繼續運作繫於人類先達成某種道德條件。

第22節先以「地一切的日子」界定範圍，再成對列出 זֶרַע／קָצִיר（播種／收割）、קֹר／חֹם（寒／暑）、קַיִץ／חֹרֶף（夏／冬）和 יוֹם／לַיְלָה（晝／夜），最後以 לֹא יִשְׁבֹּתוּ 作結；יִשְׁבֹּתוּ 來自 שָׁבַת（H7673A），本節義為「停止」。GT賈斯樂郝威據此說明，應許的是季節與農作節律不從世界中止息，局部饑荒或歉收仍可能發生。至於[[神是否改變心意]]，同一來源把本段理解為神不再以這次洪水的方式滅絕活物；彼後3:10所談的末後審判則屬跨經文延伸。CT、GT與BibleHub也按「地還存留的時候」進一步連於新天新地的盼望。

### 復活與三一神的靈訓

CT將本章整理為在基督裡死而復活：

1. 洪水消退，表示審判已過。
2. 方舟停在亞拉臘山，豫表與基督一同復活。
3. 山頂顯露，豫表與基督一同坐在天上。
4. 出方舟到更新之地，豫表行在生命新樣中。

STEP可確認第4節記的是「第七月十七日」，以及方舟在亞拉臘眾山「停住」。CT進一步把這日期與[[基督復活預表|基督復活]]相連：後來出埃及的宗教曆把原七月視為正月，逾越節在十四日，十七日遂成為第三日。這項傳統日期豫表著重經過審判而進入新生命；日期換算則採用出埃及後的宗教曆框架。

CT對新造生命的另一組教訓是：烏鴉表舊造性情，鴿子與橄欖新葉表聖靈和新生命，挪亞等候神的話才出舟，出舟後築壇把自己獻給神。這些教訓忠實保留來源的豫表框架，同時與敘事層面的歷史、曆法及鳥類背景分開。
