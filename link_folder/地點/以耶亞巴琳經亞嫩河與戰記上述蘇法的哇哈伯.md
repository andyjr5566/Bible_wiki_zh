# 以耶亞巴琳經亞嫩河與戰記上述蘇法的哇哈伯

## 定義

指民數記第二十一章紀錄以色列人自逃脫毒蛇傷害後，軍團重振信仰意志向東非曠野進程中依序度過的重要地緣節點。由日出方向（摩押之東）的以耶亞巴琳，經歷撒烈谷，直到割分摩押與亞摩利人王疆的界河「亞嫩河」。在這條挺進路上，作者徵引了早已散佚的古史綱鑑《耶和華的戰記》，用以見證上帝帶領聖徒經過蘇法的哇哈伯與各溪水之口，無畏行經強鄰與陡崖之疆，重顯上帝親任君勇帶導百姓履破難路無窮勝功。

- 本章重點：記載以色列人行旅經由日出的曠野向亞嫩谷口越邁，依據古史《耶和華的戰記》見證上帝於蘇法及哇哈伯水涯施與的大能領導。
- 與本章關聯：向聖民確立征討迦南前夕之曠野行蹤是出於上帝歷史戰局的主導與指引，強調信仰隊伍從黑暗走向向日黎明的靈性轉移。
