# 古實

## 定義

古實的希伯來名是 כּוּשׁ（H3568A），是基訓河環繞之地。STEP 在本章只把它列作專有地名，沒有直接給出「黑色、黑暗」的詞義；CT／KC 用「黑暗」作名字解釋，再延伸為生命供應臨到罪人與萬民。這是來源的字源與屬靈圖像，不是本節原文直接宣告某族群代表黑暗。

### 與目前整理書卷的關聯

古實是基訓河環繞之地。CT／KC 另以「黑暗」意象發展聖靈工作臨到萬民的應用；經文本身沒有把古實居民等同黑暗。
