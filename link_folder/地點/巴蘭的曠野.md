# 巴蘭的曠野

## 類型

地點

## 觸發來源

- 民數記 第10章

## 目前資料

巴蘭的曠野位於西乃半島中東部，北臨迦南地南地（南地曠野），南接西乃曠野。在民數記第十章中，以色列人離開西乃的曠野後，雲彩帶領他們前行，最終停住在巴蘭的曠野，這標誌著他們曠野旅程新階段的開始。

巴蘭的曠野在以色列人的曠野飄流中佔有重要地位。隨後的許多重大事件，如摩西差遣十二個探子窺探迦南地（民十三3），以及可拉一黨的叛亂等，都發生在巴蘭曠野及其鄰近的加低斯一帶。這片廣大而荒涼的區域，成為神熬煉並試驗以色列百姓信心的重要場所。
