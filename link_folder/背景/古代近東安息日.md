# 古代近東安息日

## 定義

出二十三12 的安息日命令與十誡相同，理由卻換了。GT《丁道爾聖經註釋》指出：「每星期安息一日不僅是為紀念神的創造大工（出二十11）或從埃及得拯救（申五15），更是讓以色列暫停工作，牲口藉此歇息，奴隸和半奴隸身分的工人亦可趁機舒暢。這些人大概沒有宗教上的責任。」

### 出埃及記

#### [[02 出埃及記/第23章|第23章]]
- 本章重點：出二十三12。GT《中文聖經註釋》明確指出兩處理由的差別：本節「不是誡命中所說的是紀念神創造之工的安息聖日，乃是使牛、驢，可以歇息，並使你婢女的兒子和寄居的，都可以舒暢。這是為人道的原因」。GT《啟導本聖經腳註》也說本節到13節「為二十8～11和《申命記》五12～15所立原則的延伸」。GT《中文聖經註釋》另記下撒瑪利亞抄本在「婢女」之前加有「奴僕和」等字。
- 與本章關聯：BH 指出這一節把安息日的社會公義面凸顯出來：連地位最低的人也得享安息，這正是律法一貫關懷邊緣者的表現；同時牲畜的安息也反映神對受造之物的顧念。KC 則指出在產能決定生活的時代，「貪心與不信」當道，而神願意讓人分享祂的安息並與人相交。
