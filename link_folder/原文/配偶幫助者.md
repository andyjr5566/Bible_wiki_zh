# 配偶幫助者

## 定義
創世記2章18、20節的「幫助者」是 עֵזֶר（*ezer*，H5828）；כְּנֶגְדּוֹ（*kenegdo*）以 נֶגֶד（*neged*，H5048，「在前面、相對」）為核心，並帶有「與他相對」的意思。合起來可理解為「與他相配的幫助者」。這是 STEP 可直接支持的語言層。KC、CT 與 BibleHub 再指出，聖經也以「幫助」稱神，男女又同按神形像受造，因此這裡不是把女人貶為低等助手，而是說她與男人相配、共同承擔使命；這一層是經文脈絡的神學解釋。

#### [[01 創世記/第2章|第2章]]
- 本章重點：神說人獨居不好，要為他造配偶幫助他；亞當在動物中找不到相配者，神才以肋骨建造女人。
- 與本章關聯：本章用「配偶幫助者」定義女人與男人的關係：她不是動物中的助手，也不是低於男人的附屬者，而是與他同等、相對、可共同承擔使命的人。

## 主題發展
KC 說 helper 不是貶義，因神自己也被稱為幫助；並把 suitable 解作「在他對面者」。BibleHub 以 *ezer kenegdo* 說明互補而平等的夥伴。CT 則用「相仿、相對、相配、回應者」解釋配偶。這些結論有整體經文支持，但不能說「同等」是某一個詞的字典義。

這個詞組是婚姻神學的重要基礎：神不是只補足亞當工作的缺口，而是指出人被造為關係性的存在；治理受造界不能取代人與同類之間的愛與盟約。
