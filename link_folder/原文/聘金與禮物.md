# 聘金與禮物

## 定義

希伯來文「聘金」（`מֹהַר`，*mohar*，H4119）與「禮物」（`מַתָּן`，*mattan*，H4991），為古代近東婚姻成立之法律與禮儀核心。

創世記 34:12 記載示劍求娶底拿時承諾：「任憑向我要多重的聘金（`מֹהַר`，H4119）和禮物（`מַתָּן`，H4991），我必照你們所說的給你們；只要把女子給我為妻。」

STEP 原文資料顯示，`מֹהַר`（H4119）專指男方付給女方父親的法定聘金／聘禮，`מַתָּן`（H4991）則指贈予新娘或其親屬的貴重禮物。註釋家指出，古代近東聘金金額視新娘身分與家族地位而定（努斯文獻典型為三十至四十舍客勒銀），示劍開出無上限條件凸顯其迫切與雅各家族之顯赫；然而雅各諸子轉而以「割禮」為要挾，使神聖立約記號淪為談判與欺詐之籌碼。

## 主題發展
- 聘金反映女子在父權社會中的經濟價值與法律保護
- 基督為教會捨己作「聘金」（徒20:28；弗5:25-27），超越金銀財寶
- 信徒婚姻不應以聘金多寡論價值，當以「在主裡一樣」（林前7:39）為準
