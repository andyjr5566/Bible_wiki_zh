# 吩咐、律例、典章、誡命四個詞

## 定義

申11:1 一口氣把四個詞排在一起：「你要愛耶和華─你的神，常守他的吩咐、律例、典章、誡命。」中文讀起來像同義詞堆疊，原文卻是四個不同的名詞。

STEP 顯示它們分別是：吩咐 מִשְׁמַרְתּוֹ（mish.mar.T/o，H4931，簡要詞典義 charge）、律例 חֻקֹּתָיו（chu.ko.Ta/v，H2708，statute）、典章 מִשְׁפָּטָיו（mish.pa.Ta/v，H4941G，justice 或 judgement）、誡命 מִצְוֹתָיו（mitz.vo.Ta/v，H4687，commandment）。

CT 的〔原文字義〕逐一給了中文：「吩咐」命令、（禮儀）職務；「律例」法令、條例；「典章」判決、判例、公正；「誡命」命令。它在文意註解裡再各補一句功能——『祂的吩咐』意指神所有要求遵行的命令；『律例』指律法，是神向人的要求；『典章』指審判，是神對人是否遵行律法的判定；『誡命』指十條誡。

**「常守」在原文是另一個結構。** STEP 顯示動詞是 וְשָׁמַרְתָּ（ve./sha.mar.Ta，H8104G），後面接 כָּל־הַיָּמִים（kol- hai./ya.Mim，H3117K），字面是「一切的日子」。CT 對這兩個字的解釋是：「『常守』意指始終一貫的遵守」。

**這四個詞在本章的位置是開場白。** GT《啟導本聖經申命記註釋》指出本節是十12 以後所講各事的結語，要以色列人愛神、遵行他的誡命；GT《申命記串珠聖經註釋》把它讀成一句要求——愛耶和華你的神，常守他的誡命。BH 則逐項說明它們的性質：mish.me.ret 帶著託付與職守的意思，律例是長期有效的規章，典章是就個別情況作出的司法裁決，誡命則是直接的命令。

本章結尾第32節又用其中兩個詞收束——「你們要謹守遵行我今日在你們面前所陳明的一切律例典章」，CT 在那裡給的字義與第1節一致。
