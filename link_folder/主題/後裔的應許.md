# 後裔的應許

## 定義

神對亞伯蘭的應許包含兩方面：（1）後裔如天上的星那樣無數；（2）迦南地為業。前者指向信心的子孫（新約信徒），后者指向具體的產業。

  - 亞伯蘭信耶和華，耶和華就以此為他的義
