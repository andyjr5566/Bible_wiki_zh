# 何巴

## 類型

人物

## 觸發來源

- 民數記 第10章

## 目前資料

何巴是米甸人流珥（即葉忒羅）的兒子，因此他是摩西的內兄（部分譯本譯為岳父，原文可指廣義的姻親）。在以色列人準備離開西乃山時，何巴原打算回到本鄉本土去。

摩西懇切地挽留何巴與以色列人同去，指出何巴熟悉曠野的安營地點，可以作他們的「眼目」（嚮導），並應許將神賜給以色列人的好處與他同享。何巴起初拒絕，但在摩西的再三懇求下，從後續經文（士一16；四11）可知，他最終選擇了留下，其後裔（基尼人）與以色列人同住，甚至進入了迦南應許之地。摩西對何巴的懇求，反映出在倚靠神的同時，也不排斥合理的人類經驗與幫助；而何巴的同行，則預表了外邦人因信與神的百姓同得基業。
