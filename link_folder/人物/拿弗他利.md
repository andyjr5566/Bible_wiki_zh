# 拿弗他利

## 定義

雅各第六子，拉結使女辟拉所生的第二子（創30:7-8）。和合本在創30:8 的括註作「就是相爭的意思」；CT 在同節的原文字義下作「『大大相爭』神的爭鬥；『拿弗他利』我的摔跤，角力」，GT《啟導本聖經創世記註釋》亦作「角力」。拉結說「我與我姊姊大大相爭，並且得勝」。族群後成為以色列十二支派之一，分得迦南地北部加利利地區（書19:32-39），地理位置使其受外邦影響大（賽9:1「從前神使西布倫地和拿弗他利地被藐視，末後卻使這沿海的路，約但河外，外邦人的加利利地得著榮耀」），應驗於耶穌在加利利傳道（太4:13-16）。

#### [[01 創世記/第35章|第35章]]
- 本章重點：創世記第35章中，拿弗他利被列為拉結使女辟拉所生之子，與但同列。
- 與本章關聯：本章把拿弗他利納入完整十二子名單，確認其在支派起源中的位置。

### 出埃及記

<!-- accumulation:出埃及記:1:start -->
#### [[02 出埃及記/第1章|第1章]]
- 本章重點：拿弗他利列於雅各眾子名單，是辟拉所生。
- 與本章關聯：他的後裔與全以色列一同經歷人口增長、埃及壓迫與神的保守。

## 主題發展

- 使女代孕在族長家庭中的普遍性
- 名字含義反映母親屬靈/情緒掙扎
- 支派地理位置與救恩史關聯（加利利 = 外邦人的加利利、大光照耀黑暗之地）
