# 瑪拿西

## 定義

「瑪拿西」是約瑟長子，母親是亞西納（創41:51, 46:20）。CT 的原文字義作「使之忘了，忘記」；BH 指出這名字出自希伯來文動詞 *nashah*（忘記）。約瑟解釋：「神使我忘了一切的困苦和我父的全家」（創41:51）。後成為以色列十二支派之一（以法蓮、瑪拿西雙支派取代約瑟）。

### 民數記

#### [[04 民數記/第1章|第1章]]
- 本章重點：民1:34-35 瑪拿西 32,200 人，當時人數最少。GT 丁良才指出瑪拿西當時人數最少（創48:19），但在曠野飄流期間卻加增了二萬零五百名（民26:34），參伯12:23「使邦國興旺而又毀滅」。GT 精讀本指出神超越人的意思成就自己的工作，在神揀選的工作面前人應該謙卑讚美神的旨意（羅9:18-29）。BH 指出瑪拿西後來分裂為約旦河東西兩個半支派，產業廣大反映雅各對約瑟眾子的祝福（創48:19）。

## 主題發展

「忘記」不是記憶消除。CT 指出後來的事實證明約瑟並沒有忘記父親全家的人（創42:7；43:27、30），「因此這句話較合理的解釋，指的是忘記了他對父親家人的懷怨」；丁良才說：「約瑟忘了他的苦難，卻沒有忘了他的神。」CT 並排出兩個名字的次序：「須先有瑪拿西的經歷，後才有以法蓮的經歷」——瑪拿西表明約瑟顛沛際遇的結束，以法蓮表明新生活豐盛的開展。GT《串珠聖經註釋》則說約瑟藉長子的名字，表明神已使他忘記多年的苦難以及在父家所遭遇的一切。
