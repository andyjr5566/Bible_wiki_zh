# 亞比米勒

## 定義

亞比米勒（Abimelech），意為「王（神）是我的父」。非利士王的尊號（類似「法老」、「凱撒」），不一定是個人名字。聖經中出現四位同名者。

## 主題發展

- 創二十章與創廿六章的亞比米勒是否同一人

### 聖經中的四個亞比米勒

GT 李道生《舊約聖經問題總解》〈亞比米勒有幾人？〉把同名者一次列齊，並各附行事：

1. **非利士一王**——亞伯拉罕寄居基拉耳時的王。他看見撒拉便召進宮中，夜間因神在夢中的責備將撒拉歸還；神為撒拉的緣故使他家中婦女不能生育，後因亞伯拉罕禱告才恢復。他又曾為一口水井的風波與亞伯拉罕立約（創20 全章；21:22-32）。
2. **非利士另一王**——以撒寄居基拉耳時的王。他因以撒稱妻為妹一事指責以撒，也為以撒挖水井的事與他結盟（創26:1-33）。
3. **基甸的兒子**——士師基甸之妾在示劍所生（士8:31）。基甸死後他與示劍人結黨，殺弟兄七十人，只剩下小弟兄約坦；示劍人立他為王，三年後迦勒挑唆背叛。他攻城擊敗迦勒，殺城中居民、拆毀該城並撒上鹽，又焚燒示劍樓；隨後攻取提備斯，欲焚燒城中堅固樓時被婦人拋下磨石打破腦骨而死（士9；撒下11:21）。
4. **迦特王的稱號**——非利士地迦特王亞吉也稱為亞比米勒，是瑪俄的兒子，大衛曾兩次投奔他（撒上21:10-15；27:1-12；29:1-11；詩34 篇題）。

第 3 位是關鍵：它證明這個形式**確實也能作個人名字**，而不僅是王號。因此創20 與創26 的兩位是同一人、世襲王號、或不同的同名者，單憑名字無法判定（詳見[[亞比米勒名字與王號]]）。

### 本章對他的刻畫

各家對亞比米勒的評價不完全一致。丁良才注意到第4節「連有義的國，你也要毀滅嗎」這句話，顯明他**怕神刑罰他全國的人**（7、9節）；CT 則指出他是國王、代表全國，所以他的所作所為與全國有關，而所謂「有義的國」是照世人的標準評定、並非照神的標準。GT《聖經精讀本──創世記註解》說按當時的倫理標準，他的行為並不算特別惡劣，但帶來了不好的影響，所以他的過犯須通過亞伯拉罕的中保才得赦免（17節）。

KC 的判語最不客氣：亞比米勒對神所說的話雖有幾分敬意，「**卻沒有任何認罪**」；他為自己辯解。KC 承認神在這件事上確實認可了他所說的清白與手潔，但指出即使站在神面前，這也沒有使他承認生活中其他豐富存在的罪。KC 因此把他讀成掛名信徒的寫照——在神和人面前總是維護自己，不懂得屈膝，別人的錯被他放大，自己的錯被他講成有理。

CT 從另一角度整理出一份〈認識屬世的良知〉的清單，把本章關於亞比米勒的資料排成六項：以公義自許（4節）、作事心正手潔（5節）、對神心存懼怕（8節）、對人不敢隨便得罪（9節）、肯為別人著想（14-16節）、**卻缺乏生命**（18節）。
