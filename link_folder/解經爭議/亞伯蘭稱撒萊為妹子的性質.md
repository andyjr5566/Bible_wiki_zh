# 亞伯蘭稱撒萊為妹子的性質

## 定義

亞伯蘭請撒萊在埃及稱自己為他的妹子。創世記20:12說撒萊確是亞伯蘭同父異母的妹妹，因此稱呼有血緣根據；但在創世記12章的情境中，這個說法刻意隱瞞她也是他的妻子。

## 主題發展

### 半真半假為什麼仍是謊言

各家對這一點意見一致，理由則各有側重。CT 說得最直接：撒萊確實是亞伯蘭同父異母的妹妹（創二十12），古時容許這類婚姻，「但此話半真半假，企圖以兄妹關係掩蓋夫妻關係；**以一半事實，來遮掩另一半事實，這乃是謊言**」。GT《串珠聖經註釋》把它拆成兩項錯誤：「①意圖欺騙，動機不正；②他只把事情真相說出一半」。KC 的判準落在意圖上——他所說的部分為真，「但他說這話的目的是要誤導」。GT 丁良才則指出後果面：亞伯蘭「既肯捨掉他的妻子為救自己的性命，就顯明他只顧自己，不顧別人（腓二4）」。

### 這個主題在創世記出現三次——背景註釋的功能分析

GT《舊約背景註釋》〈創十二11～12 稱妻子為姊妹〉不把它當成單一事件，而是指出「妻子／姊妹的主題在創世記中出現了三次」，並歸納出三種功用：

1. 作為外僑面對本地當權者時的**自保之法**；
2. 在創世記十二章，作為**神與被認為有神性之法老間的競爭**；
3. 在史事講述到立約子嗣受到威脅時，作為**加強懸疑成分的文學主題**。

它並解釋這個作法背後的算計：「掌權者有意將女子收入後宮時，**女子的兄弟可以和他討價還價，丈夫卻大有可能被殺害**。」這正好說明亞伯蘭為何選這個說法——兄長身分讓他從「障礙」變成「談判對象」。

背景註釋也給出一個平衡的評語：三次事件的固定結局都是「夫妻二人都不但得以團圓，還更加富裕，當地統治者則大失面子」；而「在個人的層面上，這史事對亞伯蘭貶多褒少，但與其他史事相比，則更突出他的人性」。

### 撒萊有沒有與法老同房

經文沒有記載。第19節法老說「以致我把她娶來**要作**我的妻子」，CT、丁良才與 GT《聖經精讀本》都據這句話推斷關係尚未完成——精讀本進一步說明其讀法：法老以為撒萊沒有丈夫，「因此為了經過嚴肅的儀式，正式迎娶為妻而暫時將她領進後宮」。神的介入（17節降大災）正發生在這個空檔。
