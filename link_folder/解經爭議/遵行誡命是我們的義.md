# 遵行誡命是我們的義

## 定義

第25節是全章最後一句，也是最容易讀出問題的一句：「我們若照耶和華─我們神所吩咐的一切誡命謹守遵行，這就是我們的義了。」照字面讀，義好像是靠遵行誡命換來的；這和新約說人因信稱義擺在一起，就成了一個必須處理的問題。CT、GT 的四本子註釋與 BH 都碰了這一句，答法各不相同（KC 沒有註解這一節）。

**原文只給了一個平常的字。** STEP 顯示「義」是 u./tze.da.Kah（H6666），簡要詞典義 tse.da.qah: righteousness，本節譯義 and/ righteousness；「謹守」是 nish.Mor（H8104J），「遵行」是 la./'a.Sot（H6213A）。CT 的原文字義也只寫「義」公義，公平。STEP 提供的是詞形與簡要詞典義這一層資料；整句話該怎麼理解，要看各家註釋怎麼處理它的功能。

**CT：義是滿足約的要求。** 它說這句話「意指滿足與神所立之『約』的要求，神便以我們為義，而照『約』賜福給我們」。CT 另在話中之光補一句方向：活在神的心意中是成義的路，不是人憑自己作得好，而是人在神的面光中活得對，神就承認人在祂面前有了義；它並舉挪亞與羅得為例，說他們作義人都是根據這個原則。CT 在同一段話中之光還往前推一步：律法的真正內容是神的兒子耶穌基督，而百姓憑著遵行律法可以在神面前活著，說明了人可以憑著基督在神的面前稱義——它最後一句直接說，基督「實在是我們的義」。CT 對這一節的兩個動詞也有分工：『謹守』重在指思想觀念的贊同和一致；『遵行』重在指行為上的遵照和實施。

**GT《雷氏研讀本》：把應許的範圍縮小。** 它說這句話「即遵守律法並不保證有永生，但這樣的順服卻構成得到約之祝福的權利」，並特別指出尤其是獲得土地的權利。換句話說，這裡談的義兌現的是地上的約，不是永生。

**GT《啟導本》與《串珠》：義是關係中的用語。** 《啟導本》說「“義”是就神與以色列人立約的關係而言」，要是這種關係能照神所吩咐的在日常生活上保持正當，神就賜福、保全生命、常得好處。《串珠聖經註釋》講法相同：「證明我們確實遵行了與神所立的盟約，會得著神的福澤」。兩家都把「義」讀成關係是否維持得正當的判語；它們談的是約與福澤，沒有往救恩功績的問題上走。

**GT《聖經精讀本》：正面否認衝突。** 它直說「這句話決不與保羅所闡明因信稱義的教義相矛盾」，理由是「摩西在這裡所談論的義之動機並非單單指遵守律法的外在行為而是包括愛耶和華的內在狀態」；它並引雅各書說沒有不結善果的信心，反過來若沒有敬愛追隨神的信心，也不能說真心遵行了律法。

**BH：分開救恩與生活方式。** 他說在舊約的語境裡，義常與照神律法而活相連，因此遵行誡命是在神面前彰顯義的方式；但他隨即提醒，這種義不是賺得救恩，而是活出反映神聖潔與公義的樣子，並指保羅在羅3:21-22 說明真正的義來自對耶穌基督的信。

**分歧在哪裡。** 這幾種說法回答的其實不是同一個問題。GT《啟導本》與《串珠》處理的是「這個義指什麼」——立約關係是否維持得正當、能不能得著福澤，兩家都沒有碰救恩功績的問題。GT《雷氏研讀本》處理的是「這個義換來什麼」——地上的約之祝福，而非永生。CT、GT《聖經精讀本》與 BH 則正面處理它和憑信得救的關係：CT 說不是人憑自己作得好，並把律法的真正內容指向基督；《聖經精讀本》說這句話決不與因信稱義矛盾；BH 說這種義不是賺得救恩。KC 沒有註解第25節。三個方向彼此不排斥，只是問的層次不同。

### 申命記

<!-- accumulation:申命記:6:start -->
#### [[05 申命記/第6章|第6章]]
- 本章重點：第25節「這就是我們的義了」，STEP u./tze.da.Kah（H6666，簡要詞典義 tse.da.qah: righteousness），CT〔原文字義〕「義」公義，公平。CT、GT 的四本子註釋與 BH 各自處理本節「義」的含義（KC 未註解本節）：CT 說意指滿足與神所立之約的要求，話中之光另說不是人憑自己作得好，並把律法的真正內容指向基督、說基督實在是我們的義；GT《雷氏研讀本》說遵守律法並不保證有永生，卻構成得到約之祝福（尤其土地）的權利；GT《啟導本》說義是就立約關係而言；GT《串珠》說是證明確實遵行了盟約；GT《聖經精讀本》直說這句話決不與保羅所闡明因信稱義的教義相矛盾，因為摩西所談的義之動機包括愛耶和華的內在狀態；BH 說這種義不是賺得救恩，並引羅3:21-22。
- 與本章關聯：這一節是第20至25節那段父子問答的結尾，也是全章的收束。父親要對兒子講的內容從出埃及的救贖開始（第21至23節），到第24節才講律例的目的，第25節收在義上——次序是先救贖、後誡命，這個次序本身就限制了第25節能被讀成什麼。本章開頭第1至3節說遵行帶來享福與長久，結尾說遵行就是我們的義，前後是同一套約的邏輯。
