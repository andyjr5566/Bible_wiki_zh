# 戰勝希實本與巴珊二大頑梗敵軍與佔領其廣澤領土

## 定義

指述於民數記第二十一章後段，以色列軍進攻迦南高地前夕對河東大國展開的決定性破軍勝利。面對占奪希實本、驕勇不饒的亞摩利王西宏，以及雄據肥碩巴珊好土與巨人統帥背景的巴珊王噩，摩西首以和緩通牒請行平順商旅主路遭拒；西宏與噩先後強驅重兵出擊迎擊以色列人。上帝堅宣告誡以色列勿懷驚憂，主動將二強王與其豐廣田產悉數交付神民掌握；以色列人奮起勝戰到底，完全毀滅並接收了自亞嫩河延伸至約但河與戈蘭廣大野界的所有主權。

- 本章重點：面對以西宏與噩為首的亞摩利及巴珊兩大強豪出兵攔截與進攻，上帝勉勵神軍一舉進討取得全區國境。
