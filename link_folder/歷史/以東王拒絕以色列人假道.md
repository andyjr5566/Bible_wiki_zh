# 以東王拒絕以色列人假道

## 定義

民數記第二十章於中期歷程記下了一幕關連至中東古文明親緣與國界摩擦的重大外交挫折：正當摩西意訂大隊轉自加低斯北進而向應許迦南推發，為減去翻繞荒僻阻澀之地，向占居西緬山區往南延伸的兄弟邦親以東王投奉謙誠使節：「我們在你弟兄以色列所遭遇的一切苦厄你都知道……求你容我們從你的國中經過；我們不走田地和葡萄園，也不喝井裡的冰水，只走王家大道（ King's Highway ），不偏左也不偏右，直到過了你的境界。」這般訴諸古老創世記「以掃和雅各氏為雙親連理」的古重世誼，附帶上絕不奪民資費、甚至主動購薪付酬供贖牲口的謙柔承諾，卻撞碎在以東冷厲堅決的高高拒答之上。
黃迦勒之《文摘》及丁良才之《拾穗》等文釋精嚴還原該回折衝的國族歷史意向：以東王非但斷然斥復「你不可從我國中經過，免得我帶刀出陣迎面痛擊」，更是在看到以色列試圖求和說明後，索性遣拉大把嚴肅雄壯的猛兵死守邊戍嚴堵山口；此舉暴露出以掃家世對雅各流支長期根深蒂固的恐嫌嫉懼和冷心不恭。根據《舊約聖經背景註釋》、KingComments與BibleHub考說，所謂「大道或王道」乃是縱貫外但與沙拉區、供南北往返商團和官臣快馳的最偉中道公路，借過無故遭封，代表了天路群工前去承當屬聖賞賜途中，人情凡智的眷族同袍難求長恃一靠；然而天旨並未許摩西暴起爭執血戰（參 申二4-5 ），反讓眾隊虛懷折行繞走紅海東谷，把重拒親怨留待日後俄巴底亞及先知審宣天地浩冤的高闈裁斷。

- 本章重點：詳陳摩西駐節加低斯為著直探迦南而投信血緣兄弟以東王求經王道好塗、發諾自己備資不折民草；竟遭受冷毅拒止、面臨悍兵布堵強關無情威逐的悲憤路難。
