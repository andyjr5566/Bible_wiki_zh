# 拔營起行

## 類型

歷史

## 觸發來源

- 民數記 第10章

## 目前資料

出埃及後第二年二月二十日（即以色列人抵達西乃山約十一個月後），雲彩從法櫃的帳幕收上去，以色列人便正式拔營，離開西乃的曠野。這是他們在曠野編組成軍後的第一次行軍。

此次起行完全遵照耶和華藉摩西所吩咐的順序：猶大營的纛首先起行；接著是革順與米拉利子孫抬著帳幕的結構跟隨；隨後是流便營；再接著是哥轄子孫抬著聖物（確保他們抵達前帳幕已支搭好）；之後是以法蓮營；最後由但營作為全軍的殿後。這種井然有序的行軍陣容，展現了屬神軍隊的紀律與榮耀，也預表了信徒在奔跑天路時應有的屬靈次序與合一。
