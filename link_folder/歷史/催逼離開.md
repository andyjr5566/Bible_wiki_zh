# 催逼離開

## 定義

出埃及記11:1「他容你們去的時候，總要催逼你們都從這地出去」。CT 的原文字義給「催逼」兩個意思：「趕走，驅逐」；GT《中文聖經註釋》說得更重：「原文的催逼，是含有無法容忍而以暴力驅趕的意思」，並說明範圍：「都從這地出去是一人一蹄都不留，全部男女老少和牛群羊群，埃及人都要把他們驅趕離開。」這句話與第10章28節形成一組反轉：先前是法老威脅摩西「不要再見我的面」，末災之後卻是法老主動把整族人趕出去。GT《啟導本》給了一個很生動的譯法：本節下半「原文也可作『他要像打發不要了的新婦一樣，給她厚禮送她走』」，並解釋動機：「法老巴不得把以色列人一齊趕掉，以絕後患。」

## 主題發展

- 法老態度的一路變化，丁良才在第10章已排成五格：不釋放（5:2）→在這裡祭祀（8:25）→不要走得很遠（8:28）→只許壯年人去（10:11）→留下羊群牛群（10:24）；本章第1節加上最後一格——不但放人，還要趕人走
- CT屬靈意義：世人「不見棺材不流淚，不到最後關頭不醒悟」——法老是世人剛硬心腸的屬靈寫照
- 應驗：第12章逾越節當晚法老半夜召摩西亞倫說「起來！連你們帶以色列人都從我民中出去」（出12:31）
- 呼應第6章以來「容我的百姓去好事奉我」的呼聲——最終並非法老主動放人，而是法老被神懲罰催逼放人
