# 比珥活水泉谷與眾首領用圭用杖挖井引頌讚凱歌

## 定義

記於民數記第二十一章中，當以色列部眾越進至比珥（Beer，希伯來文意為「井」或「水井」）時，耶和華未等會眾喊怨，主動向摩西宣告將召聚眾民並恩賜豐富活水。會中並未興起爭訟，反而啟發了著名的「井啊，湧上水來」讚美詩歌；十二支派的主導首領及尊貴同工們，單純攜手依靠象徵統治權限的「權圭」和引導行進的「名杖」合作深掏鬆動沉滯井土，隨即使澎湃恩泉奔躍不止。這事凸顯了信靠者以感恩頌榮替代質疑哀訴，更能經歷神極大豐沛恩流的生活準則。

- 本章重點：上帝於比珥名邑主動開口賞賜甘泉，以國民群體不發一怨高倡掘井讚美之歌，首領依賴圭與杖通力掏泉歡領豐溢恩水。
- 與本章關聯：揭破米利巴哭喊爭奪之世態，宣示以尊嚴禮歌與虔誠同心合工取代驕逆悲歌，方為引汲無窮屬靈解厄泉津的正途。
