# 拆毀偶像律例

## 定義

出二十三24：不可跪拜他們的神、不可事奉牠、不可效法他們的行為，卻要把神像盡行拆毀、打碎他們的柱像。CT 解「效法他們的行為」為「不可採行異教徒的習俗，仿效他們拜偶像假神的作法，例如與廟妓行淫、獻兒女給摩洛等」。

## 按書卷累積

### 出埃及記

<!-- accumulation:出埃及記:23:start -->
#### [[02 出埃及記/第23章|第23章]]
- 本章重點：出二十三24。GT 丁良才列出迦南諸神的名字與其祭儀中「許多暗昧可恥的事。如獻人為祭和行淫等事」，並指出這條命令針對一種戰勝國的慣例：「古時的人戰勝別國以後，就多保存那國的偶像，為本國戰勝他國的紀念品，神卻禁止以色列人這樣行。」GT《聖經精讀本》也說神「不僅命令不准跟隨他們的這種宗教習俗，更要積極地消除這種風俗」。BH 指出砸碎聖石是公開宣告這些神明無能。
- 與本章關聯：CT 由此推出一條總則：「一個人不能侍奉兩個主」，並列出四種對照（神與瑪門、神與世界、神與情慾、神與世上的榮耀）。KC 也說這些神明對他們事奉耶和華構成危險，因此必須徹底除滅。
