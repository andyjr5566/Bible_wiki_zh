# 埃及車輛與遷徙

## 定義

法老提供車輛接載雅各、婦女與孩子遷往埃及。半遊牧家族未必自備這類運輸工具，因此王室所供應的車輛既解決長途遷徙需要，也成為約瑟在埃及擁有權柄的可見證據。

## 主題發展

GT《舊約背景註釋》就第19節說明法老此舉的用意：「供應車輛並不表示埃及車輛和迦南車輛不同，而是他細心顧慮到婦孺的需要，不用他們走路前來」，並指出半遊牧民族通常不會設置車輛。GT《聖經精讀本》補上埃及的條件：埃及多有平原、曠野，馬車非常發達，而約瑟家族可以使用王室馬車，證明他們是貴賓——「埃及最高統治者如此的款待，對雅各家族決心移居埃及起了很大的作用」。丁良才則從迦南那一頭說明車輛為何能作憑據：那是兩輪的牛車，「當時在迦南地未必有車」，所以雅各一看見就知道兒子所說的是真的。CT 同說這些車輛後來成為使雅各確知約瑟仍在、且大有權柄的證據（創45:27）。
