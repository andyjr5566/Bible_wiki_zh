# 第三日與第七日的除污穢禮儀

## 定義

在出埃及行走至荒漠歲長的天約生活體系裡，面對周邊連番爆發或世局自然消損帶來的親人死故，民數記第十九章嚴密設計了一套不可妥協、分層遞進且時間觀極強的法定生命重置法規——即是關於那接觸或者共宿於世死遺屍邊緣者長達一週不潔淨的除罪歷程：「摸了人死屍的，就必七天不潔淨。那人要在第三天和第七天用這水潔淨自己，就必潔淨。」如此細密且強橫硬拒一次快速解決的時程規矩，絕非僅出自公衛或民情隔離之虞，實則在全般屬靈救恩秩序裡架造起兩重階梯式大救贖的神明視野。
黃迦勒之《文摘》及丁良才之《拾穗》等皆深度對析其中何以必須橫跨第三日與第七日雙至方准除厄除染：其一，「第三天」往往為舊造罪身迎來死心覺察及生命救贖的第一線清曙；若無於死禍降及第三天由一位全淨朋友代抱柔長牛膝草去直蘸無損母牛所鍛紅灰活泉強力揮寫彈灑在人及其居器上，那身披屍晦狂痕者即失去了救罪起始印照（如十九12強調「他第三天不潔淨自己，第七天就不潔淨」），象徵任何欲要奔至極樂休戚安適的復興靈工，絕無超越第三天蒙主的除過拯救就能自攀無礙之道；其二，「第七天」則表彰全神世界圓滿周備的靈力勝利，經歷前面自知受罪滌蕩、留待至滿程七日的洗新盡結時，此人需二度承受牛膝灑淨過往，旋隨一體俯沐自脫塵衫徹底淨水全身，便能昂聲宣布把殘骸惹致的死亡封魔撕裂乾淨，安泰步歸無災常榮的崇聖社聚。 KingComments 與 BibleHub 不止一次發號喝示，將洗災限時硬劃作此兩半不移之約，在教誨以色列平俗：解救不潔既不可輕待慢了第三日的恩誓起首，更切切不能厭倦或早斷在未滿全周七天的半途中；生死分野唯有經雙度恩臨，方獲永世的長好平安。

- 本章重點：指認全書律典對那無論手遇骸骨抑或入處傷魂凶宅皆染達一週致死污染者頒下的硬命除垢歷程；勒定在關門要津第三及第七這兩個吉定日課，依度受施牛膝草蘸牛灰活水飛揚灑身再浴神自淨的二步走回安盛況。
- 與本章關聯：深刻把解救死亡污染之儀表安著在第三日開赦印證與第七日全能得勝兩大長軸數字框架上；指實恩典雖出於自潔伴施，然而復榮康壯不可免卻任何一段從警醒直至徹浴乾鮮的神治工時。
