# 祭司與利未人的職任為神之賞賜

## 定義

民數記18:6-7中，耶和華指出利未人自眾民中遭到揀選而聯合歸主，不僅是對祭司團之重勞支援，根本為神賜下的賞賜；而後世亞倫正統系所承任長使的祭神職任，上帝同樣清楚定言：「我將祭司的職任給你們當作賞賜事奉我」。在神學底蘊下，「賞賜」二字顯出事神職與天上侍官並非藉由屬人戰功或權力政治搶逐得來的大長尊嚴，而是造化神本於豐盛憐恤與主權自發澆賜下來的白恩厚寶。這種賞賜事奉要求領荷人知難不避、以喜樂敬虔心情盡量前程，亦宣告妄圖僭奪這一份呼召的大志庸將必然無以立足且定招覆害。

- 本章重點：神宣告利未眾兵群隊與祭典亞倫祭臣之長歲奉令皆非沉工或是權位相爭，直實本相即為創造聖愛中頒下好給之賞饋恩物。
- 與本章關聯：徹底糾治肉體屬意將聖院事奉曲解作人權傲揚或抱怨枯累的謬思，還原本旨為甘美大愛之屬天揀贈。
