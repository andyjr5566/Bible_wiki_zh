# 除污穢的水

## 定義

在古以色列神權國度的曠野行軍與會幕生活規範中，「除污穢的水」是一項具備非凡赦免力與潔淨便攜價值的永恆儀例與救贖安排。根據民數記第十九章的記載，當至誠純烈的紅母牛被牽出營外，在其全體一身皮與火骨經漫烈大火焚盡並同匯香柏樹木與紅線碎膝落火融調過後，經指定委請一位素日完全不曾染染不潔之安好強民負責收取這整副寶貴厚實的紅牛柴灰；他得認真捧存至大軍主營邊緣以外絕頂安閒乾淨的專用庇地內長年封藏，隨刻預留作為全城平眾遭遇禍厄過犯致死的緊急備水素材。當凡黎子嗣於世途路行或野帳裡接觸過世死者之衰靈凶骸時，即刻自陶土空盆與聖壺器間斟落一把存備牛灰，接著滔滔添注流暢清亮的湧山溪綠「活水」使其完美交匯洗揉，即宣告誕生成一盆功效無垠的除罪聖泉。
黃迦勒、丁良才以及眾名釋者均在箋注間熱衷高揚斯項靈池體例的主旨在於解決「日常生活中無法全然躲閃的儀式不潔」；聖書經緯明定此種調除之淚其實等如同源至強的「贖罪祭」（參閱《民》十九9直言「乃是贖罪」），卻免卻了每逢一人誤撞荒骨或者家中抱老喪故即需繁難牽獻眾羊千牛血祭的大耗竭。 KingComments 與 BibleHub 更加申示，此套浩氣常泉絕不只留與本土老少以以色列本支獨享，上帝廣開慈腸宣告「這要給以色列人和他們中間寄居的外人作為永遠的定例」，說明神靈洗浴無分本國或是天涯知罪來附之眾民，一率因借著被焚烈盡卻香恆如故的那堆寶灰與生生不渝活水相逢，領有免坐永刑死害的天路更新護身契。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:19:start -->
#### [[04 民數記/第19章|第19章]]
- 本章重點：經中指明採納受化烈火燒成灰殘之純紅未負軛母牛好灰，置儲在野地營外靜逸乾淨之所，待人身蒙犯觸骸死亡不潔時伴交注進清心「活水」混攪製成的專用赦罪甘醴與長夜贖愆永遠定訓。
- 與本章關聯：建構以色列子民全境和四域寄居群黎應對意外死亡染垢時迅速取水彈洗、再獲與主安住之最高聖所行政手續；強力隱射基督之一次成極限獻死、竟為歷萬代悔罪靈眾天天供應豐沛不止滌靈活水的深浩神典。
