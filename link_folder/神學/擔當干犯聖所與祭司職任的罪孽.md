# 擔當干犯聖所與祭司職任的罪孽

## 定義

民數記18:1記載，耶和華對亞倫說：「你和你的兒子，並你本族的人，要一同擔當干犯聖所的罪孽。你和你的兒子也要一同擔當干犯祭司職任的罪孽。」「擔當罪孽」在舊約律法中含有承受刑罰與代替贖罪的雙重意義。此命令是上帝為解答以色列民對浩大天譴的恐懼與絕望而發，確立以祭司和利未支派作為捍衛聖所和消解神聖忿怒的中保屏障；凡近迫神廟核心儀件者若屬未被揀選之人在律法上為必定死亡的大咎，故唯有獲封受託的使僕家族於幔外牆界合適聯任駐看，才能有效平靖上帝威嚴並免得聖火再次擊殺民眾。

- 與本章關聯：向宣告『挨近帳幕必定絕盡死亡』的潰怯百生釋放神學救安解藥：神命親召的祭司承扛過惡重負，使全社會脫逃覆沒。
