# 第三日

## 定義

亞伯拉罕獻以撒時走了三天路程：「到了第三日，亞伯拉罕舉目遠遠的看見那地方」（創廿二4）。註解指出，這三日不是敘事的閒筆——信心不是一時的衝動，必須經得起持久的考驗；在這三天裡，以撒在他心中已經捨了，第三日彷彿把兒子從死裡得回（來十一19：他以為神還能叫人從死裡復活）。因此「第三日」成為舊約中復活意涵的重要根源：受苦與捨出在前，得回與盼望在後，豫指基督第三日從死裡復活（太十六21；路廿四7、46）（CT／GT）。

### 民數記

<!-- accumulation:民數記:19:start -->
#### [[04 民數記/第19章|第19章]]
- 本章重點：民數記19:12與19章文明確指出染死身穢者跨出沉咒七夕、朝奔痊愈聖家的大關鍵時刻為「第三日」：法令不單令得苦人需經漫曠七天洗禁，並喝陳他在這旅途其間必首先抓把握好「在第三日用這水潔淨自己」的初次引露成序；凡緩惰延失此一日程前禮者，任至第七晨昏也絕難領獲脫除病業的完滿康新赦宥。
- 與本章關聯：厚重鞏固聖卷傳統將數字「三」視成深劫重返生存、拯救自晦黑低谷邁至初更光明突破的中心印記：宣告退亡反蘇絕難虛延自來，全仰重在第三日便以清灰除沐先行成聖的意志。
