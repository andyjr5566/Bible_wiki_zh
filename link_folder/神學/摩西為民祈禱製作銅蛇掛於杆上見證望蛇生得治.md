# 摩西為民祈禱製作銅蛇掛於杆上見證望蛇生得治

## 定義

記載民數記第二十一章中，當以色列百姓遭受火蛇咬傷、面臨死亡時，主動懺悔並懇求摩西代禱。耶和華並未將全場野蛇根除，而是指示摩西製造一條沒有毒素的銅蛇，將其高舉於杆上；任何被蛇咬的百姓，只要憑著對神救贖應許的信賴抬頭仰望，便隨即活命。這一歷史奇蹟不僅在舊約中示範了神威與慈宥的挽救方法，在新約中亦由耶穌基督親自闡述，成為基督在高處成全救恩、為垂死信眾成就唯一活路的深刻預表。

- 本章重點：面對懺悔受病哀求之眾民，上帝命摩西打製無毒之銅蛇高架杆端，中毒者一抬首看仰即宣告康復得活。
- 與本章關聯：向舊新兩約昭示罪人在受刑定狀中，唯一救除死亡的關鍵不在自我修整與自割罪縛，而在信心仰瞻上主設立的預表贖主。
