# 耶和華是事奉者的業與分

## 定義

民數記18:20記載，耶和華對大祭司亞倫諭令：「你在以色列人的境內不可有產業，在他們中間也不可有分。我就是你的分，是你的產業。」隨後的23-24節也一並宣告利未支派因為專辦會幕的事，因此在全以色列同宗中不可以領有土地作為遺傳產業。這在出埃及記和舊約經典中建置起一條最高致神聖的事奉永恆保障綱律：上帝叫誠信之工僕自俗世之領土與屯利分疆競爭中完全抽離，其原因正是造萬化與賜大恩之永存主神本身，直接且不減微地化作為此群聖職侍臣胸內最無限豐厚的美好歸屬與資產庫存；這表象在於無疆自謙，實質卻在於坐享上帝無限榮恩的高尚超越。

### 民數記

#### [[04 民數記/第18章|第18章]]
- 本章重點：在廣宣告知祭儀賞祿和不可壞竭的鹽約好禮之後，主神親向亞倫及利未人言白彼等莫爭一寸紅原，原因乃是上帝本尊己成其最大、最豐富也無法傾覆的神聖資產。
- 與本章關聯：向那些常存憂算與哀悲於土野封丘的肉身知見開拓大界：得著天地最高之帝宰己心為基業者，是終究逃越了必朽世福、擁擁全安之最大歡得者。
