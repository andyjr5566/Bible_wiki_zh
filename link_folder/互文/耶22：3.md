# 耶22：3

## 定義

不可虧負寄居的、孤兒寡婦，與出22:21-22平行。

## 按書卷累積

### 出埃及記

<!-- accumulation:出埃及記:22:start -->
#### [[02 出埃及記/第22章|第22章]]
- 本章重點：GT 丁良才註解出二十二22 時，把耶利米書二十二3 列入先知斥責欺壓孤兒寡婦的經文之中。
- 與本章關聯：耶二十二3「不可虧負寄居的和孤兒寡婦，不可以強暴待他們」與出二十二21-22 幾乎逐字對應，是先知直接引用約書條款責備君王的例子。
