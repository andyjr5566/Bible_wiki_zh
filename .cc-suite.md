## Defaults

These override the built-in defaults for all commands in this project.
Remove a line to fall back to the built-in default.
`latest` is a policy, not a model name: Codex-delegating commands resolve it to
the newest general-purpose Codex model via preflight. Replace it with a concrete
slug (any entry from `/cc-suite:codex-preflight`'s model list) only to pin —
pins stop tracking the catalog.

- **Default model**: latest
- **Default effort**: high
- **Default audit type**: full
- **Default sandbox**: workspace-write

## Scripture Orchestration

- **Primary production host / reviewer**: Codex (`latest`, effort `high`)
- **Content author**: Claude `opus`, effort `max`
- **Review budget**: at most 2 substantive review attempts per stage (`m3`, `m6`, `link_updates`)
- **Codex quota fallback**: Antigravity, always the newest available Gemini **High** tier from the live `agy models` catalog — no version pinned; re-check the catalog on every handoff instead of reusing a cached/remembered slug.
- Review budget is shared across Codex/Antigravity; a handoff never resets attempts.
- Do not fall back to an older generation merely because it is named Pro.
